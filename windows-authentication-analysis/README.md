# Windows Authentication Analysis

This repository documents my analysis of Windows authentication events during Week 2 of my Blue Team Bootcamp.

## Objectives

- Understand Windows authentication events
- Analyze successful and failed logons
- Build authentication timelines
- Investigate suspicious login activity
- Practice evidence-based incident investigation

## Covered Event IDs

- 4624 - Successful Logon
- 4625 - Failed Logon
- 4634 - Logoff
- 4672 - Special Privileges Assigned

## Skills Practiced

- Windows Authentication Analysis
- Timeline Construction
- Evidence-Based Investigation
- Threat Hunting Fundamentals
- Detection Thinking
