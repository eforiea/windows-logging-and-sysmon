# Sysmon Process Analysis

This repository documents my introduction to Sysmon process telemetry during Week 2 of my Blue Team Bootcamp.

The focus is on understanding process creation events, process relationships, and correlating process activity with network connections.

## Objectives

- Understand Sysmon Event ID 1
- Investigate process creation events
- Analyze parent-child relationships
- Build simple process chains
- Practice evidence-based investigation

## Covered Topics

- Sysmon Installation
- Event ID 1
- Process Creation
- Parent Image
- Command Line
- Process Investigation

## Skills Practiced

- Process Analysis
- Parent-Child Investigation
- Timeline Construction
- Detection Thinking
