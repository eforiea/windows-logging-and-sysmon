# Windows Event Correlation

This repository documents my event correlation exercises using Windows Security Logs and Sysmon during Week 2 of my Blue Team Bootcamp.

The focus is on correlating multiple log sources to reconstruct user activity, understand process behavior, and build investigation timelines.

## Objectives

- Correlate Security and Sysmon events
- Understand the value of ProcessGuid
- Build cross-log timelines
- Practice evidence-based investigations
- Improve detection-oriented thinking

## Covered Topics

- Security Log
- Sysmon
- ProcessGuid
- Process Creation
- Network Connection
- Cross-Log Correlation

## Skills Practiced

- Event Correlation
- Timeline Reconstruction
- Investigation Planning
- Threat Hunting
- Detection Thinking
