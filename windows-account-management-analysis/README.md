# Windows Account Management Analysis

This repository documents my investigation of Windows account management events collected during Week 2 of my Blue Team Bootcamp.

The focus is on analyzing user account creation, privilege changes, password resets, and account deletion using Windows Security logs.

## Objectives

- Understand Windows account management events
- Investigate privilege-related activities
- Build event timelines
- Develop investigation hypotheses
- Practice evidence-based analysis

## Covered Event IDs

- 4720 — User Account Created
- 4724 — Password Reset Attempt
- 4726 — User Account Deleted
- 4732 — Member Added to Local Administrators Group

## Skills Practiced

- Windows Security Log Analysis
- Timeline Construction
- Account Activity Investigation
- Privilege Analysis
- Detection Thinking
