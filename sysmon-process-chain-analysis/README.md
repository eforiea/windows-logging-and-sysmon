# Sysmon Process Chain Analysis

This repository documents my analysis of Windows process chains using Sysmon telemetry during Week 2 of my Blue Team Bootcamp.

The primary objective is to understand how parent-child process relationships can reveal suspicious behaviors and support evidence-based investigations.

## Objectives

- Analyze ParentImage relationships
- Understand the value of CommandLine
- Investigate multi-stage process execution
- Correlate process creation with network activity
- Practice detection-oriented thinking

## Covered Topics

- Parent Process Analysis
- Process Chains
- CommandLine Investigation
- Network Correlation
- Evidence-Based Threat Hunting

## Skills Practiced

- Process Lineage Analysis
- Detection Thinking
- Investigation Planning
- Threat Hunting Fundamentals
