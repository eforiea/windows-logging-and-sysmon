# Sysmon Investigation Methodology

This repository documents my investigation methodology using Sysmon telemetry during Week 2 of my Blue Team Bootcamp.

The focus is not only on identifying suspicious events but also on understanding what evidence is available, what information is missing, and how to avoid premature conclusions.

## Objectives

- Analyze Sysmon process creation events
- Identify available evidence
- Identify missing context
- Build investigation hypotheses
- Practice evidence-based decision making

## Covered Topics

- Process Creation
- Parent-Child Relationships
- Command Line Analysis
- Network Connections
- Investigation Methodology

## Skills Practiced

- Incident Investigation
- Evidence Evaluation
- Threat Hunting
- Detection Thinking
- Analytical Reasoning
