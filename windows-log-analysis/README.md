# Windows Log Analysis

This project contains a basic analysis of Windows Event Viewer logs as part of my Blue Team Bootcamp.

## Objectives

- Understand the purpose of Windows Event Viewer
- Compare Application, Security, and System logs
- Extract basic log statistics
- Investigate Windows Security events
- Practice evidence-based log analysis

## Topics Covered

- Application Log
- Security Log
- System Log
- Windows Event Viewer
- Event ID 5379

## Skills

- Windows Log Analysis
- Event Investigation
- Timeline Awareness
- Evidence Collection
